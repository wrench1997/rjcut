## 产品概述

RJCut Studio 是一款基于 Web 的批量视频处理工作台，采用 React + Vite 技术构建，遵循 Apple 设计风格的极简美学。

### 核心能力

- 🎬 **批量视频处理** - 支持同时配置和提交多个视频处理任务
- ⚡ **并发控制** - 可配置最大并发任务数（1-10）
- 🔄 **自动合成** - 支持草稿完成后自动合成最终视频
- 📊 **任务管理** - 实时查看任务状态、进度和结果
- 🎨 **极简设计** - 遵循 Apple 设计系统，摄影优先，UI 退居其次

### 适用场景

- 批量处理口播视频
- 数字人视频合成
- 场景素材自动剪辑
- 字幕自动生成与对齐
- 背景音乐自动混音

## 快速开始

### 1. 访问 Studio

**开发环境：**
```bash
cd studio
npm install
npm run dev
```
访问 http://localhost:3000

**生产环境：**
直接访问部署好的 Studio 网址

### 2. 配置 API Key

1. 点击右下角 **设置** 图标
2. 输入您的 API Key
3. 点击保存（Key 仅保存在本地浏览器）

### 3. 创建第一个任务

1. 点击顶部导航栏 **批量处理** 标签
2. 配置全局参数：
   - 最大并发数：建议设置为 3-5
   - 自动合成：勾选后草稿完成自动合成
3. 添加任务配置（详见下文）
4. 点击 **验证配置** 检查任务
5. 点击 **提交任务** 开始处理

## 功能详解

### 3.1 批量处理

#### 任务配置字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 任务名称 | 文本 | 否 | 任务的自定义名称，便于识别 |
| 视频文件 | 文件路径 | **是** | 主视频文件（MP4/MOV 等） |
| 脚本文件 | 文件路径 | 条件必填 | JSON 格式脚本（纯场景模式可不填） |
| 纠错字典 | 文件路径 | 否 | JSON 格式，用于 ASR 纠错 |
| 背景音乐 | 文件路径 | 否 | MP3/WAV 等音频文件 |
| 场景素材目录 | 目录路径 | 否 | 包含场景素材的文件夹 |
| 自定义配置 | JSON | 否 | 高级参数配置 |

#### 操作步骤

1. **添加任务**
   - 点击"+ 添加空白任务"创建空任务
   - 或点击"📁 从项目添加"从现有项目填充

2. **编辑任务**
   - 展开任务卡片
   - 填写各项文件路径
   - 可使用文件浏览器选择文件

3. **验证配置**
   - 点击"🔍 验证配置"
   - 查看验证结果（错误/警告/提示）
   - 使用"一键修复"功能（如可用）

4. **提交任务**
   - 验证通过后点击"🚀 提交任务"
   - 系统自动上传文件到 OSS
   - 创建草稿任务和合成任务

### 3.2 任务管理

#### 任务状态

| 状态 | 说明 | 可操作 |
|------|------|--------|
| 排队中 | 等待处理 | 取消 |
| 处理中 | 正在执行 | 取消 |
| 草稿完成 | 草稿已生成 | 查看、合成 |
| 合成中 | 正在合成 | - |
| 已完成 | 全部完成 | 下载、预览 |
| 失败 | 处理失败 | 查看错误、重试 |

#### 操作说明

- **刷新** - 手动更新任务状态和进度
- **取消** - 取消排队中或处理中的任务
- **下载** - 下载已完成的视频文件
- **预览** - 在线预览视频（如支持）

### 3.3 文件浏览器

Studio 内置文件浏览器，支持：

- 浏览虚拟文件系统
- 按类型过滤（视频/音频/JSON/目录）
- 快速导航到常用目录
- 项目模式快速定位

**常用目录：**
- `/videos` - 视频文件
- `/audio` - 音频文件
- `/drafts` - 草稿文件
- `/scenes` - 场景素材

## 脚本格式说明

### 4.1 基础结构

脚本文件采用 JSON 格式，核心结构如下：

```json
{
  "segments": [
    {
      "flag": "human",
      "text": "大家好，今天我们来介绍...",
      "start_time": 0.0,
      "end_time": 5.5
    },
    {
      "flag": "scene",
      "text": "产品展示画面",
      "scene_file": "product_demo.mp4",
      "start_time": 5.5,
      "end_time": 12.0
    }
  ]
}
```

### 4.2 Segment 字段详解

每个 segment 代表视频中的一个片段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| flag | 字符串 | **是** | 片段类型：human/scene/transition |
| text | 字符串 | **是** | 该片段对应的字幕文本 |
| start_time | 数字 | 否 | 片段开始时间（秒） |
| end_time | 数字 | 否 | 片段结束时间（秒） |
| scene_file | 字符串 | 条件 | scene 类型必需，场景素材文件名 |

### 4.3 Flag 类型说明

#### human（人物出镜）

人物出现在画面中，通常配合口播内容。

```json
{
  "flag": "human",
  "text": "欢迎来到我们的直播间",
  "start_time": 0.0,
  "end_time": 3.5
}
```

#### scene（场景素材）

展示产品、演示画面等场景素材。

```json
{
  "flag": "scene",
  "text": "这是我们的产品外观",
  "scene_file": "product_show.mp4",
  "start_time": 3.5,
  "end_time": 10.0
}
```

**注意：**
- `scene_file` 指向场景素材目录中的文件
- 支持视频（.mp4/.mov）和图片（.jpg/.png）
- 文件名区分大小写

#### transition（转场）

用于片段之间的过渡效果。

```json
{
  "flag": "transition",
  "text": "",
  "start_time": 10.0,
  "end_time": 11.0
}
```

### 4.4 完整脚本示例

```json
{
  "segments": [
    {
      "flag": "human",
      "text": "大家好，今天我们来介绍一款新产品",
      "start_time": 0.0,
      "end_time": 4.0
    },
    {
      "flag": "scene",
      "text": "产品外观设计简洁大方",
      "scene_file": "product_exterior.mp4",
      "start_time": 4.0,
      "end_time": 8.0
    },
    {
      "flag": "scene",
      "text": "内部结构采用先进工艺",
      "scene_file": "product_interior.jpg",
      "start_time": 8.0,
      "end_time": 12.0
    },
    {
      "flag": "human",
      "text": "总结一下，这款产品非常适合日常使用",
      "start_time": 12.0,
      "end_time": 16.0
    }
  ]
}
```

### 4.5 纯场景模式

如果只需要场景素材剪辑，不需要人物出镜，可设置：

```json
{
  "custom_config": {
    "pipeline": {
      "mode": "scene_only"
    }
  },
  "segments": [
    {
      "flag": "scene",
      "text": "场景一",
      "scene_file": "scene1.mp4"
    },
    {
      "flag": "scene",
      "text": "场景二",
      "scene_file": "scene2.mp4"
    }
  ]
}
```

## 自定义配置

### 5.1 完整配置示例

```json
{
  "pipeline": {
    "remove_keyword": "转场",
    "margin": 0.15,
    "min_segment_duration": 0.1
  },
  "asr": {
    "model": "large-v3",
    "device": "cuda",
    "language": "zh"
  },
  "compose_pipeline": {
    "use_transitions": false,
    "transition_type": "fade",
    "transition_duration": 0.8,
    "resync_subtitle": true
  },
  "subtitle": {
    "effect": "ad",
    "font_size": 88
  },
  "audio": {
    "bgm_volume": 0.3,
    "original_volume": 1.0,
    "bgm_start_time": 0.0,
    "bgm_loop": true,
    "fade_in_duration": 0.5,
    "fade_out_duration": 0.5
  }
}
```

### 5.2 配置项详解

#### Pipeline 配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| remove_keyword | 字符串 | "转场" | 需要移除的关键词 |
| margin | 数字 | 0.15 | 片段边缘余量（秒） |
| min_segment_duration | 数字 | 0.1 | 最小片段时长（秒） |
| mode | 字符串 | - | 处理模式：scene_only（纯场景） |

#### ASR 配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| model | 字符串 | "large-v3" | ASR 模型 |
| device | 字符串 | "cuda" | 运行设备：cuda/cpu |
| language | 字符串 | "zh" | 识别语言 |

#### 合成配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| use_transitions | 布尔 | false | 是否使用转场效果 |
| transition_type | 字符串 | "fade" | 转场类型 |
| transition_duration | 数字 | 0.8 | 转场时长（秒） |
| resync_subtitle | 布尔 | true | 是否重新同步字幕 |

#### 字幕配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| effect | 字符串 | "ad" | 字幕效果样式 |
| font_size | 数字 | 88 | 字体大小 |

#### 音频配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| bgm_volume | 数字 | 0.3 | 背景音乐音量（0-1） |
| original_volume | 数字 | 1.0 | 原声音量（0-1） |
| bgm_start_time | 数字 | 0.0 | 背景音乐开始时间（秒） |
| bgm_loop | 布尔 | true | 是否循环播放 |
| fade_in_duration | 数字 | 0.5 | 淡入时长（秒） |
| fade_out_duration | 数字 | 0.5 | 淡出时长（秒） |

## 常见问题

### Q1: 脚本文件验证失败怎么办？

**检查以下几点：**
1. 确保 JSON 格式正确（可使用 JSON 验证工具）
2. 检查 `segments` 数组是否存在
3. 每个 segment 必须有 `flag` 和 `text` 字段
4. `scene` 类型的 segment 必须有 `scene_file` 字段

**使用一键修复：**
如果验证提示缺少 `text` 字段，可点击"一键修复"自动添加。

### Q2: 场景素材找不到？

**解决方法：**
1. 确认场景素材目录路径正确
2. 检查 `scene_file` 文件名与实际文件一致（区分大小写）
3. 确保素材文件在场景目录中
4. 支持的文件格式：.mp4, .mov, .jpg, .png

### Q3: 任务提交后一直排队？

**可能原因：**
1. 并发数设置过高，超出系统限制
2. 服务器资源紧张
3. 前序任务未完成

**建议：**
- 将并发数调整为 3-5
- 等待一段时间后刷新状态

### Q4: 如何批量处理多个视频？

**操作步骤：**
1. 点击"+ 添加空白任务"多次
2. 或使用"📁 从项目添加"快速填充
3. 为每个任务配置不同的视频和脚本
4. 一次性提交所有任务

### Q5: API Key 保存在哪里？

API Key 仅保存在您的浏览器本地存储中，不会上传到服务器。清除浏览器缓存会导致 Key 丢失，请妥善保管。
