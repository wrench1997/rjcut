# 草稿平台使用说明

## 概述

已将批量视频处理系统重构为**项目制的草稿平台**，支持按项目管理视频、JSON 脚本和配置文件。

## 主要功能

### 1. 项目制管理

- **项目结构**: 所有视频和配置文件按项目组织，存储在 `/videos/{项目名}/` 目录下
- **项目目录结构**:
  ```
  /videos/
  └── {项目名}/
      ├── project.json      # 项目主配置
      ├── scenes.json       # 场景脚本
      ├── timeline.json     # 时间线配置
      ├── raw/              # 原始视频
      ├── edited/           # 编辑中的视频
      ├── audio/            # 音频文件
      ├── subtitles/        # 字幕文件
      └── output/           # 输出视频
  ```

### 2. JSON 脚本查看器

在项目详情页的 **"📝 JSON 脚本"** 标签页中:

- **查看项目配置**: 支持查看和编辑 `project.json`、`scenes.json`、`timeline.json`
- **在线编辑**: 可直接在浏览器中编辑 JSON 配置并保存
- **语法高亮**: JSON 格式自动美化显示

### 3. 视频内容查看器

在项目详情页的 **"🎬 视频内容"** 标签页中:

- **分类浏览**: 按"原始视频"、"编辑视频"、"输出视频"分类查看
- **视频预览**: 点击视频文件即可在浏览器中播放预览
- **快速导航**: 可跳转到文件浏览器查看详细文件信息

### 4. 文件浏览器增强

- **项目导航侧边栏**: 左侧显示所有项目，快速切换
- **项目快捷方式**: 在项目目录中显示快速访问按钮（原始视频、编辑视频、音频、字幕、输出、项目配置）
- **文件类型过滤**: 支持按视频、音频、图片、文档类型过滤

## 使用流程

### 创建新项目

1. 点击 **"+ 新建项目"** 按钮
2. 输入项目名称（例如："产品宣传视频 01"）
3. 选择模板（空白项目或脚本模板）
4. 点击"创建"

### 查看项目配置

1. 在项目列表中点击项目卡片
2. 进入项目详情页
3. 切换到 **"📝 JSON 脚本"** 标签页
4. 选择要查看的脚本文件（project.json / scenes.json / timeline.json）
5. 点击"编辑"可修改配置，修改后点击"保存"

### 查看视频内容

1. 在项目详情页切换到 **"🎬 视频内容"** 标签页
2. 选择视频分类（原始视频 / 编辑视频 / 输出视频）
3. 点击视频文件进行预览
4. 可点击"在文件浏览器中打开"查看详细文件信息

### 上传视频文件

1. 在项目详情页点击 **"📁 文件"** 标签页
2. 点击对应的快捷文件夹（如"原始视频"）
3. 在文件浏览器中点击"⬆️ 上传"按钮
4. 选择要上传的视频文件

### 编辑项目配置

1. 在项目详情页切换到 **"⚙️ 设置"** 标签页
2. 修改管道配置、ASR 配置等 JSON 配置
3. 点击"保存配置"

## 项目配置说明

### project.json 结构

```json
{
  "name": "项目名称",
  "createdAt": "创建时间",
  "updatedAt": "更新时间",
  "config": {
    "pipeline": {
      "remove_keyword": "转场",    // 移除包含此关键词的片段
      "margin": 0.15,              // 边缘余量（秒）
      "min_segment_duration": 0.1  // 最小片段时长（秒）
    },
    "asr": {
      "model": "large-v3",  // ASR 模型
      "device": "cuda",     // 运行设备
      "language": "zh"      // 语言
    },
    "subtitle": {
      "effect": "ad",       // 字幕效果
      "font_size": 88       // 字体大小
    },
    "audio": {
      "bgm_volume": 0.3,      // BGM 音量
      "original_volume": 1.0  // 原始音量
    }
  },
  "scenes": [
    {
      "start_time": 0,
      "end_time": 5,
      "text": "场景文本",
      "keywords": ["关键词 1", "关键词 2"],
      "duration": 5
    }
  ],
  "timeline": []
}
```

## 界面说明

### 项目列表页

- **项目卡片**: 显示项目名称、更新时间、场景数量
- **搜索**: 支持按项目名称搜索
- **排序**: 支持按更新时间、创建时间、名称排序
- **操作**: 鼠标悬停显示复制、删除按钮

### 项目详情页

#### 概览标签页
- 项目基本信息（名称、创建时间、更新时间）
- 处理配置（管道、ASR、字幕、音频）
- 场景列表（显示所有场景的文本、关键词、时间戳）

#### JSON 脚本文签页
- 脚本文件切换（project.json / scenes.json / timeline.json）
- 查看/编辑 JSON 内容
- 保存修改

#### 视频内容标签页
- 视频分类切换（原始视频 / 编辑视频 / 输出视频）
- 视频列表
- 视频预览播放器

#### 文件标签页
- 快捷文件夹访问
- 跳转到文件浏览器

#### 设置标签页
- 编辑管道配置
- 编辑 ASR 配置
- 保存项目配置

## 技术实现

### 组件结构

- **VideoProjectManager**: 主项目管理组件
  - **ProjectCard**: 项目卡片
  - **ProjectDetail**: 项目详情页
    - **JSONScriptViewer**: JSON 脚本查看器
    - **ProjectVideoViewer**: 视频内容查看器
  - **NewProjectDialog**: 新建项目对话框

- **FileBrowser**: 文件浏览器组件
  - **ProjectQuickNav**: 项目快速导航
  - **ProjectShortcuts**: 项目快捷方式
  - **FileDetail**: 文件详情面板
  - **VideoPreview**: 视频预览组件

### 数据存储

- 使用 **IndexedDB** 存储所有文件和配置
- 支持大文件和视频存储
- 自动持久化，刷新页面不丢失数据

## 快捷键

- **双击文件/文件夹**: 打开
- **单击文件**: 选中并查看详情
- **Esc**: 关闭详情面板/对话框

## 注意事项

1. **浏览器兼容性**: 需要支持 IndexedDB 的现代浏览器（Chrome、Firefox、Edge、Safari）
2. **存储空间**: IndexedDB 配额取决于浏览器设置，通常为数 GB
3. **视频格式**: 支持 MP4、MOV、AVI、MKV、WebM 等浏览器可播放格式
4. **JSON 编辑**: 编辑 JSON 时请确保格式正确，否则无法保存
