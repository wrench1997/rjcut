# RJCut Studio 快速启动指南

## 5 分钟快速开始

### 1. 安装依赖

```bash
cd studio
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

### 3. 访问应用

打开浏览器访问：`http://localhost:5173`

## 主要功能

### 📁 项目管理

点击顶部导航的 **"项目管理"**：

- 创建新的视频项目
- 查看项目列表
- 管理项目配置
- 复制/删除项目

### 🗂️ 文件浏览

点击顶部导航的 **"文件浏览"**：

- 浏览所有文件
- 上传视频、音频、图片
- 预览媒体文件
- 搜索和过滤

### 🎬 批量处理

点击顶部导航的 **"批量处理"**：

- 配置多个视频任务
- 上传视频和配置文件
- 提交到 API 处理
- 查看处理进度

## 快速上手教程

### 创建第一个项目

1. 点击 **"项目管理"**
2. 点击 **"+ 新建项目"**
3. 输入项目名称：`我的第一个视频`
4. 点击 **"创建"**

### 上传视频

1. 点击 **"文件浏览"**
2. 导航到 `/videos/我的第一个视频/raw`
3. 点击 **"上传"** 按钮
4. 选择视频文件
5. 等待上传完成

### 预览视频

1. 在文件列表中点击刚上传的视频
2. 右侧会显示视频播放器
3. 可以播放、暂停、拖动进度条

### 创建配置

1. 导航到 `/configs` 目录
2. 双击 `default.json` 查看默认配置
3. 可以编辑并保存自定义配置

## 常用操作

### 新建文件夹

1. 在文件浏览器中点击 **📁** 按钮
2. 输入文件夹名称
3. 点击 **"创建"**

### 搜索文件

1. 在搜索框输入关键词
2. 使用类型过滤器（视频、音频等）
3. 按名称、大小、时间排序

### 上传多个文件

1. 点击 **"上传"** 按钮
2. 选择多个文件（Ctrl/Cmd + 点击）
3. 点击 **"上传"**

## 文件结构

```
/
├── drafts/          # 草稿
├── configs/         # 配置文件
├── videos/          # 视频项目 ⭐
│   └── [项目名]/
│       ├── project.json
│       ├── raw/     # 原始视频
│       ├── edited/  # 编辑视频
│       ├── audio/   # 音频
│       ├── subtitles/ # 字幕
│       └── output/  # 输出
├── audio/           # 音频文件
├── subtitles/       # 字幕文件
└── templates/       # 模板
```

## 常见问题

### Q: 文件会丢失吗？

A: 文件存储在浏览器 IndexedDB 中，只要不清除浏览器数据就会保留。

### Q: 最大支持多大的文件？

A: 取决于浏览器和磁盘空间，通常支持数 GB 的文件。

### Q: 可以在多个标签页使用吗？

A: 可以，文件系统会自动同步。

### Q: 如何备份数据？

A: 建议定期导出重要文件到本地。
