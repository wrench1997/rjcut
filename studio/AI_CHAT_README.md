# AI 聊天助手 - 使用指南

## 概述

AI 聊天助手是一个集成在 RJCut Studio 中的智能助手，可以帮助你：

- 📁 **管理项目** - 快速切换和浏览视频项目
- 📝 **生成脚本** - 自动生成视频脚本
- ✅ **检查脚本** - 验证脚本格式是否正确
- ⬆️ **上传文件** - 上传视频、音频等到项目
- 💬 **自然对话** - 用自然语言交流，获取编辑建议

## 快速开始

### 1. 确保 OpenClaw 服务运行

AI 聊天需要 OpenClaw 服务在后台运行：

```bash
# OpenClaw 应该运行在 18789 端口
http://127.0.0.1:18789/v1/chat/completions
```

如果服务未运行，请先启动 OpenClaw。

### 2. 访问 AI 助手

在 RJCut Studio 界面中，点击顶部导航栏的 **🤖 AI 助手** 按钮即可打开聊天界面。

## 使用场景

### 场景 1: 切换到项目并查看文件

```
你：/switch 产品介绍
AI: ✅ 已切换到项目：产品介绍
    路径：/videos/产品介绍
    
你：/list
AI: 📂 产品介绍 的文件:
    📁 raw
    📁 edited
    📄 script.json (15.2 KB)
```

### 场景 2: 生成脚本

```
你：/generate 公司宣传片
AI: [生成脚本预览]
    {
      "scenes": [
        {
          "start_time": 0,
          "end_time": 5,
          "text": "欢迎来到我们的公司...",
          "keywords": ["公司", "介绍"]
        }
      ]
    }
    
    [确认保存] [重新生成]
```

### 场景 3: 上传文件

```
你：/upload
AI: 📤 准备上传文件到 产品介绍
    
    请选择要上传的文件类型...
    
[选择文件后]
AI: ✅ 文件上传成功！
    文件名：intro.mp4
    路径：/videos/产品介绍/intro.mp4
    大小：25.3 MB
```

### 场景 4: 自然语言交流

```
你：我想为新产品创建一个视频，有什么建议？

AI: 为新产品创建视频，我建议：

1. **开头** (0-5 秒): 展示产品外观，吸引注意力
2. **功能介绍** (5-20 秒): 突出核心功能
3. **使用场景** (20-40 秒): 展示实际应用
4. **用户评价** (40-50 秒): 增加可信度
5. **购买引导** (50-60 秒): 明确的行动号召

需要我帮你生成一个脚本吗？
```

## 快捷按钮

聊天界面底部提供了快捷按钮，点击即可快速输入常用命令：

- 📁 **切换项目** - 快速切换到其他项目
- 📝 **生成脚本** - 生成新的视频脚本
- ✅ **检查脚本** - 验证脚本格式
- 📂 **列出文件** - 查看当前项目文件
- ⬆️ **上传文件** - 上传文件到项目

## 文件结构

AI 聊天会将生成的脚本和上传的文件保存到虚拟文件系统中：

```
/videos/
  ├── 项目名 1/
  │   ├── raw/          # 原始素材
  │   ├── edited/       # 编辑后的文件
  │   ├── audio/        # 音频文件
  │   ├── subtitles/    # 字幕文件
  │   ├── output/       # 输出文件
  │   └── project.json  # 项目配置
  └── 项目名 2/
      └── ...
```

## 与 OpenClaw 集成

AI 聊天使用 OpenClaw 的 API 进行对话：

- **API 端点**: `http://127.0.0.1:18789/v1/chat/completions`
- **默认模型**: `claude-4-opus`
- **支持流式**: 是
- **温度**: 0.7

如果需要修改配置，请编辑 `src/components/AIChat.jsx` 文件中的常量：

```javascript
const OPENCLAW_API_URL = 'http://127.0.0.1:18789/v1/chat/completions'
const DEFAULT_MODEL = 'claude-4-opus'
```

## 注意事项

1. **OpenClaw 服务**: 确保 OpenClaw 服务正在运行，否则 AI 聊天无法工作
2. **项目路径**: 切换项目时，使用项目的准确名称（不包含路径）
3. **文件格式**: 上传文件时，支持常见的视频、音频和文档格式
4. **脚本格式**: 生成的脚本遵循 RJCut 的标准 JSON 格式

## 故障排除

### AI 不响应

- 检查 OpenClaw 服务是否运行
- 检查浏览器控制台是否有错误信息
- 确认 API 端点地址正确

### 无法切换项目

- 确认项目名称正确
- 使用 `/projects` 查看可用项目列表
- 检查项目是否存在于 `/videos/` 目录下

### 脚本生成失败

- 确认网络连接正常
- 检查 OpenClaw 服务日志
- 尝试简化生成请求
